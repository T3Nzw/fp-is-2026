ghci> product [1,2,3]

## Задача 03

Да се напишат имплементации на следните функции:

- `head :: [a] -> a`, която връща първия елемент на подадения списък;
- `tail :: [a] -> [a]`, която връща нов списък без първия елемент на подадения;
- `init :: [a] -> [a]`, която връща нов списък без последния елемент на подадения;
- `last :: [a] -> a`, която връща последния елемент на списък;
- `butLast :: [a] -> a`, която връща предпоследния елемент на списък.

**Пример**:

```hs
ghci> head [1,2,3]
1
ghci> tail [1,2,3]
[2,3]
ghci> init [1,2,3]
[1,2]
ghci> last [1,2,3]
3
ghci> butLast [1,2,3]
2
```

## Задача 04

Да се дефинират следните функции:

- `append :: [a] -> [a] -> [a]`, която конкатенира два списъка;
- `reverse :: [a] -> [a]`, която обръща реда на елементите в списък;
- `take :: Int -> [a] -> [a]`, която връща списък, съдържаща първите `n` елемента на списъка;
- `drop :: Int -> [a] -> [a]`, която връща списък, който не съдържа първите `n` елемента на списъка;
- `dropEvery :: Int -> [a] -> [a]`, която връща нов списък, който не съдържа всеки `n`-ти елемент в оригиналния;
- `insertAt :: Int -> a -> [a] -> [a]`, която вмъква елемент на дадена позиция в списъка;
- `zip :: [a] -> [b] -> [(a,b)]`, която обединява два списъка в нов списък, чиято дължина е равна
  на по-малката от двете дължини на списъците.

**Пример**:

```hs
ghci> append [1,2,3] [4,5,6]
[1,2,3,4,5,6]
ghci> reverse [1,2,3]
[3,2,1]
ghci> take 3 [1..10]
[1,2,3]
ghci> drop 3 [1..10]
[4,5,6,7,8,9,10]
ghci> dropEvery 2 [1..10]
[1,3,5,7,9]
ghci> insertAt 2 [1,2,3]
[1,2,0,3]
```

## Задача 05

Да се дефинира функция, която приема позиция и списък и връща наредена двойка от списъци,
първият от които съдържа елементите на списъка преди позицията, а вторият - елементите
на списъка след (и включително) позицията.

**Пример**:

```hs
ghci> splitAt 1 [1,2,3]
([1],[2,3])
ghci> splitAt 10 [1,2,3]
([1,2,3],[])
```

## Задача 08

Да се дефинира функция, която приема списък от елементи от произволен тип и връща
списък от всички последователности от еднакви елементи в списъка. Имаме ли някакви
допълнителни изисквания върху елементите в списъка?

**Пример**:

```hs
ghci> pack [1,2,3,4,4]
[[1],[2],[3],[4,4]]
ghci> pack "aabbbd"
["aa","bbb","d"]
```

## Задача 09

Да се дефинира функция, която приема списък с елементи от произволен тип, и връща неговия
run-length encoding (RLE). Имаме ли някакви допълнителни изисквания върху елементите в списъка?

**Пример**:

```hs
ghci> rle "aaabcca"
[(3,'a'),(1,'b'),(2,'c'),(1,'a')]
ghci> rle [5,2,2,5]
[(1,5),(2,2),(1,5)]
```
