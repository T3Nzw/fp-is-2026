## Задача 01

Да се напишат следните функции от по-висок ред:

- `map :: (a -> b) -> [a] -> [b]`;
- `filter :: (a -> Bool) -> [a] -> [a]`;
- `all :: (a -> Bool) -> [a] -> Bool`;
- `any :: (a -> Bool) -> [a] -> Bool`;
- `zipWith :: (a -> b -> c) -> [a] -> [b] -> [c]` - по два начина, използвайки директна рекурсия и използвайки `map`;
- `takeWhile :: (a -> Bool) -> [a] -> [a]`;
- `dropWhile :: (a -> Bool) -> [a] -> [a]`;
- `span :: (a -> Bool) -> [a] -> ([a],[a])`.

## Задача 02

Да се напише функция, която приема едноместна функция `f` и затворен интервал, зададен чрез двата си края,
и връща броя на неподвижните точки на `f` в този интервал.

**Пример**:

```hs
ghci> fixpoints id 1 10
10
```

## Задача 03

Да се напише функция `compose`, която приема две функции и връща тяхната композиция.
Какви трябва да бъдат типовете на двете функции? Какъв е типът на връщаната функция?
Да се дефинира операторът `.`, който е синтактична захар за композицията на две функции,
така че да е възможно следното:

```hs
ghci> let comp = even . (+1)
ghci> comp 3
True
```

## Задача 06

Да се дефинира функция, която приема компаратор от тип `a -> a -> Ordering`
и списък от елементи от тип `a` и сортира този списък, използвайки компаратора.
За колко различни начини на имплементация се сещате?

> [!NOTE]
> Компаратор е функция на два аргумента, която задава линейна наредба между елементите
  от някакъв тип. В случая сме избрали като резултат да се връща нещо от тип `Ordering`.
  Това е т.нар. алгебричен тип данни, дефиниран много подобно (откъм функционалност е същото)
  на изброим тип в C++. Има три стойности - LT, EQ, GT (съответно отговарящи на релациите
  <, == и >). Причината да дефинираме горната функция по указания начин, е, че в стандартната
  библиотека за списъци `Data.List` типът на горната функция е именно
  `sortBy :: (a -> a -> Ordering) -> [a] -> [a]`.

## Задача 08

Правоъгълник в равнината ще представяме чрез две точки, обозначаващи горната лява
и долната дясна точка на правоъгълника. Допълнително всеки правоъгълник има свой уникален
номер (цяло число), който го характеризира.

Нека е даден списък от такива правоъгълници в равнината. Да се дефинират следните функции,
работещи над такъв списък:

- функция, която за всеки правоъгълник в списъка намира неговото лице;

- функция, която приема реално число и връща списък от всички правоъгълници,
  които имат лице, по-голямо или равно на подаденото число;

- функция, която приема цяло число в интервала [1;4], представящо квадрант в равнината,
  и връща всички правоъгълници, които се намират в дадения квадрант;

- функция, която проверява дали съществува правоъгълник, който е изроден, т.е.
  двете му точки лежат на една и съща права;

- функция, която връща правоъгълника с пореден номер `n`;

- функция, която намира правоъгълника, чиято най-лява точка се намира възможно най-вляво на
  координатната система. Ако има повече от един такъв правоъгълник, да се върне първият срещнат.
  Търсим линейна времева сложност на решението.
