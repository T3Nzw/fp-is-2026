## Задача 01

Да се дефинира функцията `succ :: Int -> Int`, която връща наследника на дадено естествено число.
Да се дефинират следните функции, използвайки само `succ` или вече дефинирани функции:

- `pred :: Int -> Int`, която намира предшественика на дадено естествено число.
  Приемаме, че предшественикът на 0 е 0;
- `add :: Int -> Int -> Int`, която добавя две числа;
- `mul :: Int -> Int -> Int`, която умножава две числа;
- `ack :: Int -> Int -> Int`, която реализира функцията на Акерман,
  дефинирана по следния начин:

  - $Ack(0,n) = n+1$

  - $Ack(m, 0) = Ack(m-1, 1), m>0$

  - $Ack(m,n) = Ack(m-1, Ack(m, n-1)), m > 0, n > 0$

```hs
ghci> succ 5
6
ghci> pred 6
5
ghci> add 5 6
11
ghci> mul (succ 3) (pred 5)
16
ghci> ack 1 2
4
ghci> ack 2 2
7
```

## Задача 03

Да се дефинира функция, която реализира алгоритъма за бързо степенуване,
дефиниран по следния начин:

$$
\begin{equation}
  x^n =
    \begin{cases}
    (x^2)^{n/2}, & n \mod 2 \equiv 0  \\
    x.x^{n-1}, & n \mod 2 \equiv 1  \\
    \end{cases}
\end{equation}
$$

**Пример:**
```hs
ghci> quickPow 2 5
32
```

## Задача 05


## Задача 06

Да се дефинира функция, която приема цяло число `n` и връща дали то е число на Капрекар.
Казваме, че едно число е число на Капрекар, ако съществува разбиване на лява (`lhs`) и дясна (`rhs`) част
на квадрата на числото `n`, така че `lhs + rhs == n`.

**Пример:**
```hs
ghci> kaprekar 45
True  -- 45^2 = 2025 и 20 + 25 = 45
ghci> kaprekar 9
True  -- 9^2 = 81 и 8 + 1 = 9
```
